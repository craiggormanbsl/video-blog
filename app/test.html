Stream / SharePoint Authentication Test

This page tests whether a SharePoint-hosted video can be played using the Microsoft Stream embed player and the user's existing Microsoft 365 authentication.

Open video/player in new tab

If the Stream player displays a Microsoft sign-in screen, complete the Microsoft 365 sign-in inside the player if permitted. If the video plays afterwards, this demonstrates that the Stream/SharePoint player can manage access to the protected video without this application retrieving the MP4 itself.

If the player reports that sign-in is blocked, cookies are blocked, the content cannot be displayed in a frame, or the browser refuses the SharePoint iframe, record the exact error. Do not attempt to work around Microsoft security controls.
