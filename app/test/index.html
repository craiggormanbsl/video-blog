SharePoint media test

This standalone page tests SharePoint image and video URLs without changing the main player. For a useful comparison, first open the same file URL directly in this browser and complete any sign-in prompt, then return here and test it.

Image test

A successful load confirms this browser can display this image URL in the page. A failure is not definitive proof of an auth problem: the browser intentionally hides cross-site HTTP status, and blocked cookies, redirects, permissions, network policy, or an invalid URL can look similar.

Video test (optional)

This requests video metadata first, not the entire file. If metadata loads but playback buffers or fails, file size/network throughput may contribute; codec support, SharePoint auth, or byte-range streaming can also be involved. The page cannot identify the exact cause on its own.
